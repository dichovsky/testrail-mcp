## Outcome

Provide an installable local stdio server package foundation with reproducible builds.

Implement within the accepted local-stdio design: one TestRail identity per process; one tool per endpoint; every operation enabled by default, including writes/admin/delete; no server-added confirmation. TestRail 10.7.0 is the full-coverage baseline; older versions are best effort.

Architecture: [accepted design](https://github.com/dichovsky/testrail-mcp/blob/codex/testrail-mcp-plan/docs/architecture.md). Exact engineering contract: [implementation contracts](https://github.com/dichovsky/testrail-mcp/blob/codex/testrail-mcp-plan/docs/implementation-contracts.md). [Endpoint inventory](https://github.com/dichovsky/testrail-mcp/blob/codex/testrail-mcp-plan/docs/operation-inventory.json).

## Dependencies

None. This item can begin independently.

Tracking epic: [full TestRail MCP release](https://github.com/dichovsky/testrail-mcp/issues/1).

## Scope

- Create @dichovsky/testrail-mcp with bin testrail-mcp, TypeScript strict mode, ESM, npm lockfile, MIT license metadata, package files allowlist, source maps and clean build output.
- Use Node engines ^22.13.0 || >=24; certify Node 22 and 24 on Linux/macOS/Windows. Pin MCP server 2.0.0, test client 2.0.0 and compatible Zod 4 exactly; use exact driver 7.0.0 for development until F03 adopts the published release qualified by F01.
- Establish src/cli.ts plus config, driver, runtime, operations, contracts, files and transport boundaries. Use a focused test runner such as Vitest, type checking and linting; keep production dependencies separate from test seams.
- Add CI for clean npm ci, build, typecheck, lint, tests and npm pack dry-run. Add --help/--version paths that need no TestRail environment.

## Acceptance and verification

- [x] A clean checkout builds and tests reproducibly on the six OS/Node combinations; package contents exclude fixtures, private files and credentials.
- [x] A packed tarball installs into an isolated prefix and its executable resolves on supported platforms; --help/--version exit successfully without starting MCP or contacting TestRail.
- [x] The package exposes only intended public files and pins direct runtime dependencies. Document later Node majors as best effort until certified.
