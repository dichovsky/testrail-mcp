# Lint with oxlint and tsgolint so TypeScript 7 is the only compiler

typescript-eslint cannot load under TypeScript 7, so keeping ESLint meant a second compiler and a duplicate typecheck gate. We chose oxlint with oxlint-tsgolint, which runs on its own embedded TypeScript 7 checker and needs no `typescript` package. Against ESLint it matched all 23 type-aware rules on ESLint-validated fixtures, flagged all 11 planted violations through SDK, zod and client types, and reported exactly the same 834 floating-promise and 30 unused-expression sites after 872 awaits were stripped from real code. Biome, the other candidate, had no equivalent for 7 of those 23 rules and caught 1 of 7 promises into Node builtins. This accepts one tsgolint false positive suppressed in place; `no-unsafe-optional-chaining` off in `tests/`, where oxlint sees through casts that ESLint does not; two `eslint:recommended` rules oxlint does not ship (`no-dupe-args` and `no-octal`, both strict-mode syntax errors in this ESM-only code); two nursery rules (`no-undef` and `no-useless-assignment`); and type-aware behavior that Oxc does not cover by semver, so both packages are pinned exactly and updated together. Revisit if a release breaks a gate or typescript-eslint supports TypeScript 7 natively.
